PHASE 2: UNDERSTANDING THE 6 PROVEN DETECTION MODULES IN "project555"
--------------------------------------------------------------------------------
You must copy/adapt the exact working logic and models from `project555`:

1. MODULE 01: Real-Time Walking Assistance (`01_real_time_walking_assistance/`)
   - Tech: OpenCV DNN MobileNet SSD / YOLOv8 with monocular distance triangulation.
   - Spatial logic: 3-corridor analysis (Left, Center, Right) + directional cues:
     "Walk Straight", "Steer Left", "Steer Right", "Stop - Obstacle Ahead".
   - Model: `models/frozen_inference_graph.pb` or `yolov8n.pt`.

2. MODULE 02: Approaching Vehicle Detection (`02_approaching_vehicle_detection/`)
   - Tech: Multi-target optical bounding box expansion rate (dA/dt) tracking.
   - Physics: Time-to-Collision (TTC) model.
   - Alert: Immediate high-priority voice warnings if a vehicle is closing in fast.

3. MODULE 03: Obstacle & Path-Hazard Detection (`03_obstacle_and_path_hazard_detection/`)
   - Tech: Multi-zone spatial computer vision:
     * Floor adaptive contrast cavities for pothole detection.
     * Sobel filter + Hough transform for staircase/step edge detection (up/down).
     * Upper eye-level edge density for low tree branches / overhead bars.
     * Specular glint reflection analysis for wet/slippery floors.

4. MODULE 04: Familiar Person Recognition (`04_familiar_person_recognition/`)
   - Tech: Deep metric learning using OpenCV YuNet face detector + SFace 128-D matcher.
   - Models:
     * `04_familiar_person_recognition/models/face_detection_yunet_2023mar.onnx`
     * `04_familiar_person_recognition/models/face_recognition_sface_2021dec.onnx`
   - Features: Encodes reference photos from `known_faces/` (supports .jpg, .png, .heic).
     Provides spatial position ("Sandra is in front of you, 2 meters away").

5. MODULE 05: Indian Currency Recognition (`05_currency_recognition/`)
   - Tech: MobileNetV3 deep classifier trained for Indian banknotes (10, 20, 50, 100, 200, 500, 2000).
   - Weights: `05_currency_recognition/indian_currency_mobilenet.pth`.
   - Stability: 4-frame Temporal Consistency Filter (prevents noisy flickering).
   - Features: Automatic denomination voice announcement + running wallet tally.
   - Training pipeline: `train_classifier.py` using PyTorch CrossEntropyLoss & Adam.

6. MODULE 06: Text Reading / OCR (`06_text_reading/`)
   - Tech: Dual-mode OCR engine:
     * Mode 1 (Live Spotter): Fast signboard & product label detection.
     * Mode 2 (Document Reader): Windows native WinOCR / EasyOCR with structured
       sentence parser and voice controls (Pause, Repeat, Next).

7. SHARED INFRASTRUCTURE (`shared/`):
   - `shared/camera_stream.py`: High-throughput zero-latency threaded camera reader.
   - `shared/audio_engine.py`: Non-blocking SAPI speech queue with priority interrupts.
   - `shared/vision_utils.py`: Standard HUD overlays, distance calculation, bounding boxes.
   - `shared/voice_listener.py`: Background speech recognition hotword/command listener.

8. MASTER DISPATCHER (`main.py`):
   - Unified master application that allows hands-free voice switching between all modules:
     "Walking assistance", "Vehicle detection", "Hazard", "Person", "Currency", "Read text".
